# Module 3 Reference — Use After Your Own Attempt

This folder contains post-attempt comparison material. Complete the Detailed Build Guide, Practice workbook and ten Stage Validation gates before using these references.

## Included

- `03_Module_03_Practice_Workbook_COMPLETED.xlsx` — completed learner-equivalent evidence, reasoning and validation record.
- `M_Reference_Scripts/` — canonical M comparison scripts for functions, resilient preparation, folding, error handling and reusable architecture.
- `PowerBI_Reference_Artifacts/Module_03_Data_Preparation_Lab.pbix` — completed native Data Preparation reference.
- `PowerBI_Reference_Artifacts/Module_03_Folding_Performance_Lab.pbix` — completed native Folding & Performance reference.
- `PowerBI_Reference_Artifacts/Module_03_Native_PBIX_SHA256.csv` — final integrity fingerprints.

## Reference-use rule

The reference layer is intentionally separate from `Practice/`, `Source_Files/` and `Validation/`. Build and diagnose first; compare afterward. If a result differs, return to the evidence chain rather than copying the completed output blindly.

The two Power BI files are final native reference artifacts. Source paths and local SQL endpoints can be environment-specific, so use the Detailed Build Guide to rebind them when needed without altering the frozen expected results.
