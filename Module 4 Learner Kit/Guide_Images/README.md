# Module 4 Guide Images

The Stage 3 Detailed Build Guide is intentionally self-contained and does not depend on decorative screenshots.

During the native Power BI build, add a screenshot only when it materially prevents ambiguity in a version-sensitive or multi-dialog path (for example relationship properties, storage mode, Manage aggregations, or Assume referential integrity). The final learner package may contain extracted copies of any images embedded in the frozen guide/reference build.
