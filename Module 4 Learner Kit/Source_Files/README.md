# Module Four Source Files

This Stage Two source estate extends the fully sealed Module Three environment for semantic-modeling work.

- `SQL/` contains the deterministic Module Four database extension, validation queries, DirectQuery/aggregation observer, and Assume referential integrity comparison.
- `Model_Sources/` contains inspectable file mirrors/specimens for date/time, SCD2, fact types, bridges, hierarchies and relationship labs.
- `Broken_Model_Variants/` contains controlled defects only; never substitute them for healthy final model sources.
- `Specifications/` contains metadata, relationship and date/time design contracts.

The inherited Module Three database truth remains unchanged: 4 regions, 9 technologies, 12 plants, 500,000 interval rows and 50,000 battery interval rows.
