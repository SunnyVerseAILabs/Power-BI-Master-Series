# Guide Images

This folder is reserved for version-specific interface screenshots used with the Detailed Build Guide when a visual reference materially prevents ambiguity.

Power BI Desktop, SQL Server and SSMS interfaces can change between releases. If a screenshot differs from your current installation, follow the concept, field names, expected state and validation instructions in `../01_Module_02_Detailed_Build_Guide.docx` rather than assuming an older screen layout is authoritative.

The text guide remains the primary execution reference.
