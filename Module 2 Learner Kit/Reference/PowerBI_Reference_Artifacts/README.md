# Power BI Reference Artifacts

Use these completed artifacts **after building your own versions** from the Detailed Build Guide. They are supplied so you can compare the expected end state without replacing the hands-on learning process.

Included:
- `Module_02_File_Connectivity_Lab.pbix`
- `Module_02_SQL_Connectivity_Lab.pbix`
- `Module_02_Import_Lab.pbix`
- `Module_02_DirectQuery_Lab.pbix`
- `Module_02_Parameterized_Connectivity_Template.pbit`

Important:
- PBIX/PBIT connections can require new credentials or source rebinding on another computer.
- The SQL artifacts assume a working local `SunnyVerseRenewableGroup` database and the SQL endpoint you validated in SSMS.
- The file-connectivity PBIX can contain source paths from the machine where it was built; treat those paths as reference state and reconnect to your own working-copy files when needed.
- The Import and DirectQuery files answer the same minimal business question so you can compare execution behavior rather than visual design.
