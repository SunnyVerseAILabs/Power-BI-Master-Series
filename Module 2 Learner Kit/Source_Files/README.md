# Source Files

These are the authoritative Module 2 learner inputs.

## File connectors
- `SunnyVerse_Source_Objects.xlsx`
- `Regions.csv`
- `Generation_7Day_Sample.txt`
- `Technology_Status.json`
- `Maintenance_Events.xml`
- `Portfolio_Snapshot.parquet`

## Folder connector
`Monthly_Extracts/` contains July, August and September 2026 generation extracts.

## Web connector
`GitHub_Web/` contains the files that can be opened from the public course repository by selecting **Raw** in GitHub and copying the raw-file URL into Power BI's Web connector.

## SQL Server
`SQL/` contains the complete local database build, validation, DirectQuery workload-observation and optional SQL-authentication scripts.

## Broken variants
`Broken_Source_Variants/` contains controlled failure files. Use them only when the Detailed Build Guide instructs you to do so.

Do not alter the clean source files in place. Use working copies for rename/move/failure exercises.
