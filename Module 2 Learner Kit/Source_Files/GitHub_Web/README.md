# GitHub Web Connector Files

Use these files from the public SunnyVerse course repository for the Web connector activity:

1. Open one of the files in GitHub.
2. Select **Raw**.
3. Copy the raw-file URL.
4. In Power BI Desktop choose the **Web** connector.
5. Use **Anonymous** authentication for these public course files.
6. Classify them as **Public** for this training scenario.

Required lab file: `Regions_Public.csv`  
Optional second example: `Technology_Status_Public.json`
