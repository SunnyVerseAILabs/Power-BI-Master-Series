# Practice

`03_Module_02_Practice_Workbook.xlsx` is your learner evidence workbook for Module 2.

Use it while following `01_Module_02_Detailed_Build_Guide.docx`.

The workbook records:
- environment and version evidence;
- all main Get Data entry paths;
- Desktop option states;
- connector and Navigator observations;
- awareness-only cloud connector recognition;
- SQL endpoint and advanced-option evidence;
- credential and privacy decisions;
- Data Source Settings and source-change evidence;
- connection parameters;
- Import versus DirectQuery evidence;
- refresh observations;
- failure diagnosis and recovery;
- PBIX/PBIT/PBIP understanding;
- version/file-management evidence;
- final SQL reconciliation;
- checkpoint completion.

Complete your own workbook first. After your attempt, use `../Reference/03_Module_02_Practice_Workbook_COMPLETED.xlsx` to compare classifications, expected observations, failure diagnoses and final reconciliation.
