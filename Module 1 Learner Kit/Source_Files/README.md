# Source Files

Use this folder for the supplied business and data inputs referenced by the Detailed Build Guide.

These files are intentionally **not all clean**. Some contain duplicates, missing values, inconsistent codes, stale information, conflicting authoritative values, or grain combinations designed to test analytical reasoning. Do not repair a file simply because it looks imperfect; first determine what the issue means, which quality dimension it affects, and what business decision could be harmed.

`Business_Context/Stakeholder_Request.md` contains the original stakeholder statements. The same scenario is reproduced and fully explained inside the Detailed Build Guide so you can work entirely from the guide if you prefer.

The clean final reconciliation datasets are not stored here. They are located under `../Validation/Final_Reference_Data/` because they represent the corrected authoritative state rather than working input.
